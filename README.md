# 🎮 GamePlay

Aplicativo mobile desenvolvido em **React Native** com **Expo** para conectar jogadores e organizar partidas com amigos no Discord.

🔗 **Protótipo no Figma:** [Acessar layout no Figma](https://www.figma.com/design/fcZm7GOxjOcuZF27RsnShb/GamePlay---NLW-Together--Copy-?node-id=58913-83&p=f&t=aHqCAYKNAreUEp3Y-0)

---

## 📱 Telas Desenvolvidas

- **Splash**: Tela de abertura com logo do app.
- **Login**: Autenticação com botão do Discord.
- **Home**: Perfil do usuário, modal de logout, categorias e lista de partidas agendadas.
- **Detalhes do Servidor**: Informações da partida, lista de jogadores (com status) e botão para entrar.
- **Agendar Partida**: Servidor pré-selecionado, seleção dinâmica de categoria com checkbox, inputs de data/horário/descrição e suporte ao teclado com `KeyboardAvoidingView`.

---

## 🧩 Componentes Reutilizáveis

- **`ButtonIcon`**: Botão estilizado com ícone do Discord e divisória vertical.
- **`CategorySelect`**: Barra horizontal de categorias com controle de seleção e checkbox.

---

## 🛠️ Tecnologias

- **React Native**
- **Expo**
- **JavaScript**

---

## 🚀 Como Executar

```bash
# 1. Clone o repositório
git clone https://github.com/ySamantha/GamePlay.git

# 2. Acesse a pasta
cd GamePlay

# 3. Instale as dependências
npm install

# 4. Inicie o projeto
npx expo start
```

Abra o app **Expo Go** no celular e escaneie o QR Code gerado no terminal.
